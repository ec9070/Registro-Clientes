# Registro-Clientes

Una aplicación de escritorio simple y personalizada que lleva un registro de los clientes y sus terapias en un negocio de terapia física, construida 100% en Python, utilizando una versión modificada de Tkinter para la interfaz gráfica.

# Tecnolgías
- Python
- Tkinter
- Sqlite

# Características
- Registrar, editar y eliminar clientes
- Buscar cliente por identificación
- Registrar, editar y eliminar terapias físicas para el cliente
- Ver una lista ordenada por fecha de todas las terapias y poder filtrarla por cliente
